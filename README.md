# llm-studies

Repositório para reunir os meus estudos sobre Large Language Models (LLMs): anotações, resumos de papers, experimentos de código e prompts testados.

## Estrutura

- `notas/` — anotações e resumos de estudo (conceitos, cursos, artigos)
- `papers/` — papers lidos, com resumos e principais ideias
- `projetos/` — código e experimentos práticos com LLMs
- `prompts/` — prompts testados, templates e técnicas de prompt engineering

## Status

Repositório em construção — vou atualizando conforme avanço nos estudos.
